# Vision-Language Model (VLM) Integration Module

This directory houses the Vision-Language Model (VLM) components for the joint doctorate multimodal framework, combining:
- **Visual stream inputs** from OAK-1 / edge camera frames,
- **Graph soft tokens** from `src/bridge/gnn_llm_projector.py`, and
- **Vision-language backbone reasoning** for joint visual-spatial trajectory diagnostics.
